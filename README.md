# Robotic Arm Servo Controller

This project is a simplified and modular Arduino sketch for controlling a 6-DOF robotic arm using buttons and a potentiometer. It was adapted from an original Instructables tutorial by **Beaconsfield**.

🔗 Original Tutorial: [Very Simple Robotic Arm - Instructables](https://www.instructables.com/Very-Simple-Robotic-Arm/)

## What's Included:
- Refactored Arduino code using arrays and helper functions
- Button and servo control logic
- Notes for future expansion (e.g., EEPROM, serial input)
